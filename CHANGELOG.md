# Changelog

Notable changes to Guard the Flock are recorded here. This project uses Semantic Versioning; see [README.md](README.md#versioning).

## [7.0.0] - 2026-10-15

### Changed
- Replaced browser-side RSS proxy fetching with a static JSON news snapshot generated by a scheduled GitHub Actions workflow.
- Added a manual workflow dispatch for refreshing the latest news snapshot on demand.
- Added reliable loading, snapshot timestamp, safe-link validation, and unavailable-state messaging to Latest News.
- Retained category filtering and publisher/source attribution.

### Added
- Added `scripts/update_news.py` to fetch and normalize RSS/Atom feeds, including The Roys Report.
- Added `.github/workflows/update-news.yml` to refresh `data/news.json` every four hours.
- Added repository version metadata in `VERSION`.
- Added maintained wiki source pages under `docs/wiki/`.

### Notes
- Feed failures are isolated per publisher. If every feed fails and a previous snapshot exists, the generator preserves that snapshot.
- No API keys or external Python packages are required.

## [6.0.0] - 2026-10-15
