# Changelog

Notable changes to Guard the Flock are recorded here. This project uses Semantic Versioning; see [README.md](README.md#versioning).

## [8.2.0] - 2026-10-20

### Changed
- Added the cell/small-group Discussion Guide under Resources (it is retained in Warning Signs & Discernment for cross-reference).

### Added
- Added *A Church Called Tov* by Scot McKnight and Laura Barringer, the Logos Spiritual Abuse Recovery Guide, and Tears of Eden to Resources.

## [8.2.1] - 2026-10-20

### Changed
- Consolidated the Resources/Discussion Guide updates with the audited link repairs into one release bundle.
- Clarified publisher attribution and corrected the status notes in the link-audit handoff.

## [8.1.0] - 2026-10-20

### Changed
- Corrected confirmed broken, mismatched, or unrelated external resource/case links based on the link audit.
- Removed the missing social preview image declaration and set the canonical Open Graph URL to the GitHub Pages site.
- Replaced dead archive paths with verified publisher pages/searches where appropriate; removed unsafe or unverified organization domains.
- Added the complete `link-audit-report.md` handoff with status, limitations, and remaining human verification items.
- Documented private FreshRSS as an optional discovery tool only; the public site remains manually curated with no auto-published feed.

## [8.0.0] - 2026-10-20

### Changed
- Removed the automated Latest News tab and RSS pipeline so broad or unrelated headlines are not published automatically.
- Retained the manually curated case-specific links in Documented Cases, including Roy's Report references.
- Updated README and wiki guidance to describe the manual research and curation workflow.

### Removed
- Removed the feed generator, generated `data/news.json`, and scheduled RSS workflow.
- Documented FreshRSS as an optional private reader for discovering candidate stories that are manually reviewed before being added as case links.

## [7.5.0] - 2026-10-20

### Changed
- Repaired confirmed broken journalism/resource links and removed unrelated or unsafe destinations.
- Replaced dead topic URLs with current search pages only where a relevant search is available; relabeled broad destinations honestly.
- Replaced ProPublica's dead topic/series links with its live church-abuse investigation series.
- Corrected the Open Graph canonical URL and removed the missing social preview image reference.

### Removed
- Removed links to the CFM loan site, unverified spiritual-abuse domain, and broken general-news/search destinations.

## [7.4.0] - 2026-10-15

### Changed
- Prioritized the listed specialist sources in Latest News, led by The Roys Report, with newest stories first within each publisher.
- Added author/writer bylines from publisher RSS/Atom metadata when available; bylines are omitted rather than inferred when absent.
- Updated README and wiki guidance for source ordering and byline attribution.

## [7.3.0] - 2026-10-15

### Changed
- Prioritized listed specialist church-accountability publishers in Latest News, led by The Roys Report.
- Added bylines when author/creator metadata is available in the publisher's feed.
- Preserved publisher attribution when feeds omit writer metadata; the site does not infer authors.

## [7.2.0] - 2026-10-15

### Changed
- Narrowed Latest News to explicit spiritual/sexual abuse, church financial misconduct, and institutional accountability topics.
- Removed broad religion, national, and regional news feeds that admitted unrelated headlines.
- Added context-plus-topic filtering against RSS titles and summaries and issue-specific UI filters.
- Regenerated `data/news.json` with only relevant stories.
- Added same-case deduplication to reduce repeated publisher rewrites while preserving distinct follow-up reporting.

## [7.1.0] - 2026-10-15

### Changed
- Focused Latest News on church-related spiritual/sexual abuse, clergy misconduct, church financial fraud, safeguarding, and institutional accountability.
- Removed general religion, national, and regional news feeds from the source list.
- Added relevance filtering using feed titles and descriptions; unrelated items are excluded.
- Replaced broad source filters with issue-focused categories.
- Updated README and wiki operations guidance to document the relevance rules.

## [7.0.0] - 2026-10-15

### Changed
- Replaced browser-side RSS proxy fetching with a static JSON news snapshot generated by a scheduled GitHub Actions workflow.
- Added a manual workflow dispatch for refreshing the latest news snapshot on demand.
- Added reliable loading, snapshot timestamp, safe-link validation, and unavailable-state messaging to Latest News.
- Retained category filtering and publisher/source attribution.

### Added
- Added `scripts/update_news.py` to fetch and normalize RSS/Atom feeds, including The Roys Report.
- Added `.github/workflows/update-news.yml` to refresh `data/news.json` every four hours.
- Added repository version metadata in `VERSION`.
- Added maintained wiki source pages under `docs/wiki/`.

### Notes
- Feed failures are isolated per publisher. If every feed fails and a previous snapshot exists, the generator preserves that snapshot.
- No API keys or external Python packages are required.
